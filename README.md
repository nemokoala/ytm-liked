# 좋아요한 곡 뷰어

YouTube Music에서 좋아요한 곡 전체를 무한 스크롤 없이 한 화면에서 보는 로컬 웹앱이에요.

- 전체 목록을 한 번에 불러와 PC에 저장해 두므로, 다음부터는 바로 열려요. 저장된 목록이 하루 이상 지났으면 열 때 뒤에서 자동으로 새로 불러와요.
- 제목, 아티스트, 앨범으로 검색할 수 있고 초성 검색도 돼요(예: `ㄴㅈㅅ` → 뉴진스).
- 열 제목을 누르면 좋아요한 순서, 제목, 아티스트, 앨범, 길이로 정렬해요.
- 아티스트나 앨범 이름을 누르면 해당 곡만 걸러서 보여줘요.
- 곡을 누르면 오른쪽 플레이어에서 재생하고, 지금 보이는 목록 순서대로 이어서 재생해요(셔플 가능).
- 곡에 마우스를 올려 ☆를 누르면 즐겨찾기에 들어가고, 위쪽 **즐겨찾기** 버튼으로 즐겨찾기한 곡만 볼 수 있어요. 즐겨찾기는 내 YouTube Music 계정의 비공개 재생목록 "즐겨찾기 (좋아요 뷰어)"에 저장돼서, 다른 PC에서도 똑같고 휴대폰 YouTube Music 앱에서도 재생목록으로 보여요.

## 실행

`run.bat`(Mac은 `run.command`)을 더블클릭하세요. 처음 실행할 때 `.venv`를 만들고 필요한 패키지를 설치한 뒤, 브라우저에서 http://127.0.0.1:8765 를 열어요.

직접 실행하려면:

```bash
pip install -r requirements.txt
python app.py
```

## 다른 PC에서 쓰기

Python 3.10 이상과 Git이 있으면 돼요.

```bash
git clone https://github.com/nemokoala/ytm-liked.git
```

받은 폴더에서 `run.bat`(Mac은 `run.command`)을 실행하고, 그 PC의 브라우저에서 아래 "처음 연결하기"를 한 번 해 주세요. 로그인 정보(`data/`)는 저장소에 올라가지 않아서 PC마다 따로 연결해요. 새 버전은 `git pull` 후 `run.bat`(Mac은 `run.command`)을 다시 실행하면 반영돼요.

## 처음 연결하기

YouTube Music에는 공식 API가 없어서, 비공식 라이브러리 [ytmusicapi](https://github.com/sigma67/ytmusicapi)와 브라우저 로그인 헤더를 사용해요.

> **파이어폭스를 쓰세요.** 크롬(146 이상)과 엣지는 로그인 쿠키를 그 PC에 묶어 두는 보안 기능(DBSC)이 있어서, 복사한 로그인이 10분쯤 뒤 끊겨요. 파이어폭스에는 이 기능이 없어서 로그아웃하기 전까지 유지돼요.

1. 파이어폭스에서 music.youtube.com을 열고 로그인해요. 연결한 뒤에도 파이어폭스에서 로그아웃하지 마세요.
2. `F12` → **네트워크(Network)** 탭 → 필터 칸에 `browse`를 입력해요.
3. YouTube Music 화면에서 **보관함** 같은 메뉴를 하나 눌러요.
4. `POST browse?…` 요청을 우클릭하고 **값 복사 → 요청 헤더 복사**(Copy Value → Copy Request Headers)를 눌러요. cURL로 복사한 것도 돼요.
5. 앱의 연결 창에 붙여넣고 **연결**을 눌러요.

헤더는 `data/browser.json`에 저장돼요. 로그인 쿠키가 들어 있으니 공유하지 마세요. 로그인이 풀리면 앱이 알려 주니, 그때 ⚙ 버튼에서 다시 연결하면 돼요.

## 단축키

| 키 | 동작 |
| --- | --- |
| `/` | 검색창으로 이동 |
| `Esc` | 검색어 지우기 |
| `Space` | 재생 / 일시정지 |
| `N` / `P` | 다음 곡 / 이전 곡 |
| `S` | 셔플 켜기 / 끄기 |
| `-` / `+` | 볼륨 5씩 내리기 / 올리기 (볼륨 칸 위에서 마우스 휠도 돼요) |
| `M` | 음소거 / 해제 |
| `F` | 지금 재생 중인 곡 즐겨찾기 추가 / 빼기 |
| `L` | 목록에서 지금 재생 중인 곡으로 이동 |
| 키보드 미디어 키 ⏮ ⏯ ⏭ | 이전 곡 / 재생·일시정지 / 다음 곡 (브라우저가 뒤에 있어도 돼요) |

## 참고

- 재생은 YouTube 임베드 플레이어를 써요. 임베드가 막힌 곡은 자동으로 건너뛰고 흐리게 표시해요. 그런 곡을 누르면 YouTube Music에서 열려요.
- 비공식 API라 구글이 내부 구조를 바꾸면 새로고침이 실패할 수 있어요. 그때는 `.venv\Scripts\python -m pip install -U ytmusicapi`로 라이브러리를 업데이트해 보세요.
- 서버는 `127.0.0.1`에서만 열려서 같은 PC에서만 접속할 수 있어요.
