YouTube Music 연결

로그인된 브라우저에서 요청 헤더를 한 번만 복사해 오면 돼요. 비밀번호는 필요 없어요.

파이어폭스에서 복사하세요. 크롬과 엣지는 보안 기능(DBSC) 때문에 복사한 로그인이 10분쯤 뒤 끊겨요.

  1. 파이어폭스에서 music.youtube.com을 열고 로그인하세요. 연결한 뒤에도 파이어폭스에서 로그아웃하지 마세요.
  2. F12 → 네트워크(Network) 탭을 열고 필터 칸에 browse를 입력하세요.
  3. YouTube Music 화면에서 보관함 같은 메뉴를 하나 눌러 요청이 생기게 하세요.
  4. POST browse?… 요청을 우클릭 → 값 복사 → 요청 헤더 복사(Copy Value → Copy Request Headers)를 누르세요.
  5. 아래 칸에 붙여넣고 연결을 누르세요. cURL로 복사한 것도 돼요.

헤더에는 로그인 쿠키가 들어 있어요. 이 PC의 data/browser.json에만 저장되고 다른 곳으로 보내지 않아요. 다른 사람에게 공유하지 마세요. 유튜브에서 로그아웃하면 다시 연결해야 해요.
